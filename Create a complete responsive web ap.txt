Create a complete responsive web application called **“Campus SnackPass – Canteen Pre-Ordering & Live Token Pass”** using only:

* HTML5
* CSS3
* Bootstrap 5.3.3
* Bootstrap Icons
* Vanilla JavaScript

Do NOT use React, Angular, Vue, Tailwind CSS, jQuery, or any backend framework.

## 1. Overall Concept

Build a modern college canteen pre-ordering website where students can:

* Browse vegetarian food items
* Search menu items
* Filter by category and diet
* Sort food items
* Customize food items
* Add items to an order tray/cart
* Apply coupon codes
* Select pickup counter
* Schedule pickup time
* Select payment method
* Use a campus wallet
* Generate a digital order token
* View token/order history
* Track order progress
* View a live canteen TV/kiosk screen

The application should look like a polished, modern college food-ordering system.
